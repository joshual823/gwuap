# Gwuap — context for Claude Code

Before doing anything else in this project, read `BUILD_GUIDE.md` in this
same folder. It's the up-to-date source of truth for:

- What's been built and confirmed working (check the `[x]` boxes)
- What session/feature is currently in progress
- Key decisions already made (naming, design direction, what's
  deliberately deferred, moderation policy, etc.)

The person you're working with is a coding beginner who's comfortable in
a terminal but learning as they go. Prefer clear explanations over dense
jargon, and confirm before taking any action that touches production
(Vercel, the live Supabase database, git pushes to the shared repo).

If you make a meaningful change or complete a build-guide checklist item,
update `BUILD_GUIDE.md` to reflect it before ending the session, so the
next session (whether in Claude Code or the regular chat) stays accurate.
